# what's your age again? — support site

The public support and privacy page for **what's your age again?**, an iPhone app that shows
your age in years, days, minutes, and ticking seconds.

Live page: https://acpurohit1.github.io/whats-your-age-support/

This repository contains only the static support page (`index.html`). The app's source code
lives elsewhere and is not published here.
